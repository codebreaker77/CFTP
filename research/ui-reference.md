# Workspace design references

The requested reference is MongoDB Atlas, using its navigation patterns and
LeafyGreen component guidance as inspiration rather than copying its branding.

- Clear server/resource context in a persistent top bar.
- A compact sidebar grouping Files, Activity, and Broadcasts.
- White content surfaces, subtle gray borders, readable type, and restrained green actions.
- Task labels such as “Files” and “Upload files”, replacing decorative slogans.
- Tables with explicit actions, accessible dialogs, and useful empty states.
- Broadcast recipient state and verification are visible without adding unrelated dashboards.
