Quick start

A quick way to try your workspace.

  1. Start the local workspaceIn the project folder, run:python -m cftp.web --demo
  2. Send something smallDrop a text file here or choose Upload files.
  3. Bring it backDownload it from the file list. Every transfer is checked with SHA-256.

Already running a CFTP server? Start with python -m cftp.web and use Connection settings.
